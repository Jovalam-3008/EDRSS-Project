# Storytelling del dashboard EDRSS V2

El tablero sigue una conversación de negocio, no una colección de gráficos.

| Hoja | Pregunta | Decisión habilitada |
|---|---|---|
| Resumen ejecutivo | ¿Cuál es la situación actual? | Definir prioridad y capacidad general |
| Riesgo y mora | ¿Cuándo y dónde se concentra el problema? | Identificar ventanas y segmentos críticos |
| Comportamiento | ¿Qué diferencia a un cliente con mora? | Comprender señales accionables |
| Modelo predictivo | ¿Podemos confiar en el score? | Aprobar o vigilar el modelo |
| Priorización | ¿A quién contactar primero? | Descargar la cola diaria de cobranza |
| Calidad de datos | ¿Son confiables los consumibles? | Autorizar o detener la actualización |

## KPIs principales

- Tasa de mora observada.
- Población disponible para scoring.
- ROC-AUC y PR-AUC OOT.
- Recall, precisión y lift a capacidad del 10%.
- Clientes críticos y de alto riesgo.
- Registros aprobados, advertidos o fallidos por calidad.
